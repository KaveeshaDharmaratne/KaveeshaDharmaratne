## 🔌 IoT and Embedded Projects

Personal and academic projects where I explore hardware, firmware, and connected devices.

### 🤖 Desk Assistant · ESP32-S3 Voice Assistant

An embedded voice assistant that combines presence detection, speech recognition, conversational AI, and audio playback.

- Detects nearby users with an HC-SR04 ultrasonic sensor and starts a conversation automatically
- Captures 16 kHz microphone audio through an I2S pipeline
- Transcribes speech with OpenAI Whisper and generates replies with OpenAI Chat
- Streams synthesized speech from ElevenLabs to an I2S speaker
- Uses a structured state machine and configurable hardware settings

**Built with:** C++, ESP32-S3, PlatformIO, I2S, OpenAI Whisper, ElevenLabs, ArduinoJson

A real-time embedded system that detects vibration patterns and triggers alerts.

- Edge Impulse machine learning model support

### 📍 Student GPS Tracker

A hardware tracking device for monitoring location in real time.

- ATmega328P microcontroller with an A9G GPS/GSM module
- MQTT telemetry pipeline delivering location data to a web dashboard with Google Maps
- Prototype achieved accuracy under 5 metres with updates every 10 seconds

**Built with:** C/C++, ATmega328P, A9G GPS & GSM, MQTT, Google Maps API
